# Divergent DAMP-family regulation and cell-cycle coupling of HMGB1 during dengue and Zika virus infection

Re-analysis of public virus-inclusive single-cell RNA-seq (viscRNA-seq) data from Zanini et al. (2018, *eLife*), decomposing HMGB1 downregulation into cell-cycle-mediated versus virus-specific components in DENV and ZIKV infection of Huh7 cells.

**Target journal:** Virologica Sinica

## Data source

- **Dataset**: GSE110496 (NCBI GEO)
- **Original publication**: Zanini F, Pu SY, Bekerman E, Einav S, Quake SR. Single-cell transcriptional dynamics of flavivirus infection. *eLife*. 2018;7:e32942.
- **Access**: https://doi.org/10.7554/eLife.32942

No new raw data were generated. This repository contains analysis code only.

## Environment

- R version 4.4.1
- Key packages: Seurat v5.1.0, ggplot2 3.5.1, patchwork

```r
# Install R dependencies
install.packages(c("Seurat", "ggplot2", "patchwork"))
```

## Setup

1. **Obtain the processed Seurat objects.** Place `denv_cc.rds` and `zika_clustered.rds` in the `data/` folder. These objects are generated by running the preprocessing pipeline (`00_preprocessing.R`) from the raw GEO matrices (GSE110496): standard QC (200–7,500 genes, <10% mitochondrial reads), normalization, scaling, PCA (top 20 PCs), UMAP (n.neighbors=30, min.dist=0.3), Louvain clustering (resolution 0.5), and cell-cycle scoring (Seurat `CellCycleScoring`). The objects contain metadata columns: `orig.ident`, `nCount_RNA`, `nFeature_RNA`, `virus`, `MOI`, `time`, `viral_load`, `viral_log`, `S.Score`, `G2M.Score`, `Phase`, `seurat_clusters`.

2. Run all analyses with one command:

```r
Rscript run_all.R
```

## Reproducibility notes

- All scripts start with `set.seed(123)` for reproducibility.
- High-viral clusters are auto-detected (highest median viral_log), not hardcoded.
- Infection threshold: `viral_log > 0.5`.
- Cell cycle scoring uses Seurat's built-in human gene set (`cc.genes`).
- Pseudobulk analysis is **descriptive only** (no biological replicates available).
